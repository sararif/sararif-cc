# sararif-cc — ใส่ซับไทยลง CapCut ด้วยคำสั่งเดียว

> เครื่องมือที่ผมใช้จริงทุกวันกับ 3 ช่องของตัวเอง เอามาแบ่งให้ใช้
> ยังไม่ได้ขัดเกลาให้สวย แต่ใช้งานได้จริง — ถ้าติดตรงไหนบอกได้

---

## ปัญหาที่ตัวนี้แก้

CapCut ทำซับไทยอัตโนมัติได้ **แต่แบ่งบรรทัดไม่เป็น**

ผมทดสอบบนมือถือจริงเมื่อ 31 ส.ค. 69 กับคลิปพูด 45 วินาที:

| | ผลที่ได้ |
|---|---|
| **CapCut auto-caption** | ซับ **3 ก้อน** ก้อนละ 11–20 วินาที · ข้อความ 5–7 บรรทัดค้างบนจอทีเดียว **อ่านไม่ทัน** |
| **ตัวนี้** | ซับ **39 บรรทัด** บรรทัดละ ~1 วินาที · ไม่ตัดกลางคำ · ไม่ทิ้งคำเชื่อมค้างท้าย |

สาเหตุที่ CapCut ทำไม่ได้: **ภาษาไทยไม่มีเว้นวรรค** มันเลยหาจุดแบ่งวลีไม่เจอ (ภาษาอังกฤษมันแบ่งให้ปกติ)
ตัวนี้ใช้ **pythainlp** ตัดคำไทยจริง แล้วแบ่งบรรทัดตามกฎที่ผมกลั่นมาจากงานจริง

---

## กฎการแบ่งบรรทัดที่ใส่ไว้

1. **ไม่ตัดกลางคำ** — ตัดคำด้วย pythainlp newmm
2. **ไม่ทิ้งคำลงท้ายไว้โดด** — `ครับ ค่ะ คะ จ้า นะครับ อะ อ่ะ เนี่ย ปุ๊บ` เกาะท้ายบรรทัดเดิมเสมอ
3. **ขึ้นบรรทัดใหม่ที่คำเชื่อม** — `ก็ ซึ่ง แต่ เพราะ ดังนั้น พอ ถ้า`
4. **ไม่ปล่อยคำเชื่อม/บุพบทค้างท้ายบรรทัด** — `ใน จาก กับ ที่ ว่า ไม่ ต้อง จะ ได้` และอีก 27 คำ
5. **คุมความยาว** ไม่ยาวเกิน ไม่สั้นเกิน

**ตัวอย่างที่ต่างกันจริง:**

```
ก่อน:  ...มีความสามารถใน    ←  "ใน" ค้างท้าย อ่านสะดุด
       การหาเงิน...
หลัง:  ...มีความสามารถในการ
       หาเงิน...

ก่อน:  จุดที่เราต้อง        ←  ประโยคปิดถูกหั่นเป็น 2 ท่อน
       วางแผน
หลัง:  จุดที่เราต้องวางแผน
```

| ของ | จำเป็นไหม | ติดตั้งยังไง |
|---|---|---|
| **Mac** | ✅ จำเป็น | ดูหัวข้อ Windows ข้างล่าง |
| **CapCut เวอร์ชันคอม** | ✅ จำเป็น | โหลดฟรีจาก capcut.com แล้วเปิดสร้างโปรเจกต์ 1 ครั้ง |
| **Bun** | ✅ จำเป็น | `curl -fsSL https://bun.sh/install \| bash` |
| **Python 3** | ✅ จำเป็น | Mac มีมาให้แล้ว |
| **pythainlp** | ✅ จำเป็น | `python3 -m pip install pythainlp` |
| **ffmpeg** | ✅ จำเป็น | `brew install ffmpeg` |
| **ทางได้ข้อความ** | ✅ ต้องมี 1 ใน 3 | ทาง A ไม่ต้องติดตั้งอะไร — ดูหัวข้อถัดไป |
| ฟอนต์ "มหานคร" | ⬜ ไม่บังคับ | ไม่มีก็ใช้ฟอนต์ default ของ CapCut |

### ⭐ ทาง A · ฟรีจริง ไม่ต้องติดตั้งอะไร ไม่ต้องมีคีย์ (เริ่มที่นี่)

**CapCut ถอดเสียงให้ฟรีอยู่แล้ว** — ปัญหาเดียวคือมันแบ่งบรรทัดไม่เป็น
เราเลยไม่ต้องถอดใหม่ แค่**อ่านของที่มันทำไว้แล้วมาแบ่งใหม่**

```
CapCut → เลือกคลิป → Text → Auto captions → ภาษาไทย → รอถอดเสร็จ → ปิด CapCut ให้สนิท
```

```bash
bun cc.ts ชื่อโปรเจกต์ --engine capcut --dry
```

**ไม่ต้องใส่ไฟล์คลิปด้วยซ้ำ** เพราะข้อความกับเวลาอยู่ในโปรเจกต์อยู่แล้ว
ถ้ามีข้อความหลายแทร็ก มันจะขึ้นรายการให้เลือก แล้วเติม `--track <เลข>`

### ทาง B · ElevenLabs Scribe — เวลาแม่นระดับคำ

สมัครที่ https://elevenlabs.io เอา API key มาใส่ไฟล์เดียว จบ

```bash
echo 'ELEVENLABS_API_KEY=คีย์ของคุณ' > ~/.sararif-cc.env
```

ราคาราว **฿1 ต่อคลิป 3 นาที** · ใช้ได้กับ Mac ทุกรุ่น · **เวลาแม่นระดับคำ** เอาไปเลือกจุดตัดต่อได้จริง
(ใช้คีย์ของคุณเอง ผมไม่ได้แถมคีย์ และไม่ได้เก็บค่าอะไรจากตรงนี้)

### ทาง C · whisper.cpp ในเครื่อง — ฟรี แต่มีข้อแลก 2 ข้อ

```bash
brew install whisper-cpp

mkdir -p ~/.sararif-cc/models
curl -L -o ~/.sararif-cc/models/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

> ⚠️ **ข้อแลกที่ 1 — เวลาเพี้ยน** วัดจริงกับคลิปพูด 45 วินาที: วินาทีที่ 42 ถูกรายงานเป็น **53**
> ยิ่งคลิปยาวยิ่งเพี้ยน **เอาไปเลือกจุดตัดต่อหรือทำ cc ไม่ได้** เหมาะกับ "อยากรู้ว่าพูดอะไร" เท่านั้น
>
> ⚠️ **ข้อแลกที่ 2 — ติดตั้งนานถ้า Mac ไม่ใหม่พอ** brew มีตัวสำเร็จรูปให้เฉพาะ **macOS Sonoma (14) ขึ้นไป**
> ถ้าเครื่องเป็น **Ventura (13) หรือ Monterey (12)** มันจะ compile เอง **อาจกินเวลา 20–40 นาที**
> เช็คเวอร์ชันเครื่องด้วย `sw_vers -productVersion` · บวกโหลดโมเดลอีก ~1.5GB
>
> **ถ้าเครื่องไม่ใช่ Sonoma ขึ้นไป ข้ามทาง C ไปเลย** — ใช้ทาง A ที่ฟรีและไม่ต้องติดตั้งอะไรดีกว่า

โมเดลเล็กกว่าใช้ `ggml-base.bin` (~150MB) เร็วกว่าแต่แม่นน้อยกว่า
เก็บ whisper/โมเดลไว้ที่อื่นสั่งทับได้ด้วย `WHISPER_CLI=...` และ `WHISPER_MODEL=...`

## เริ่มใช้

**1. ตรวจเครื่องก่อน — อันนี้ทำเป็นอย่างแรกเสมอ**

```bash
bun doctor.ts
```

มันจะบอกว่าขาดอะไร **พร้อมคำสั่งที่ต้องพิมพ์** ก๊อปไปวางได้เลย ขึ้น `✅ พร้อมใช้งาน` ถึงไปต่อ

**2. เปิด CapCut สร้างโปรเจกต์ ใส่คลิปลงไทม์ไลน์ แล้วปิด CapCut**

จำชื่อโปรเจกต์ไว้ (ชื่อที่ตั้งใน CapCut นั่นแหละ)

**3. ดูก่อนว่าจะแบ่งบรรทัดยังไง (ยังไม่เขียนลงโปรเจกต์)**

ทางฟรี — กด Auto captions ใน CapCut ก่อน แล้วปิด CapCut จากนั้น:
```bash
bun cc.ts ชื่อโปรเจกต์ --engine capcut --dry
```

ทางที่มีคีย์ Scribe / whisper — ใส่ไฟล์คลิปแทน:
```bash
bun cc.ts ชื่อโปรเจกต์ ~/Downloads/คลิปของคุณ.MOV --dry
```

**4. พอใจแล้วค่อยเขียนจริง — เอา `--dry` ออก**

```bash
bun cc.ts ชื่อโปรเจกต์ --engine capcut
```

**5. เปิด CapCut ดูผล** — ถ้าซับไม่ขึ้น ให้ปิด CapCut สนิทก่อนแล้วเปิดใหม่ (มันแคชไฟล์ไว้)

## ตัวเลือกที่มี

```bash
bun cc.ts <โปรเจกต์> [คลิป...] [ตัวเลือก]

--dry                  แบ่งวลีให้ดูอย่างเดียว ไม่เขียนลง CapCut
--engine capcut        อ่านซับที่ CapCut ถอดไว้แล้ว (ฟรี · ไม่ต้องใส่ไฟล์คลิป)
--engine scribe|local  ถอดเสียงใหม่จากไฟล์คลิป (ต้องมีคีย์ / whisper)
--track N              เลือกแทร็กข้อความ (ใช้กับ --engine capcut)
--keep-source          ไม่ต้องลบซับเดิมของ CapCut (ค่าปกติคือลบให้)
--maxchars 16          ความยาวสูงสุดต่อบรรทัด
--y -0.80              ตำแหน่งแนวตั้ง (-1 = ล่างสุด)
--size 15              ขนาดตัวอักษร
```

**หลายคลิปในโปรเจกต์เดียว** — ใส่ต่อกันได้ ระบบจะคิดจุดเริ่มให้เองตามความยาวไฟล์

```bash
bun cc.ts myproj a.MOV b.MOV
bun cc.ts myproj a.MOV:0 b.MOV:12.5      # หรือกำหนดวินาทีที่เริ่มเอง
```

## ⚠️ เรื่องที่ต้องรู้ก่อนใช้

**ปิด CapCut ก่อนเสมอ** — CapCut เก็บโปรเจกต์ทั้งก้อนไว้ในหน่วยความจำ แล้วเขียนทับตอนปิด
ถ้าเราแก้ไฟล์ตอนมันเปิดอยู่ **งานจะหายเงียบๆ ตอนคุณกด Cmd+Q**
ตัวนี้ปิด CapCut ให้เอง และถ้าเช็คไม่ได้ว่าปิดแล้วจริง **มันจะไม่ยอมเขียน** (ยอมไม่ทำ ดีกว่าทำแล้วงานหาย)

**มีไฟล์สำรองให้เสมอ** — ก่อนเขียนจะสำรองเป็น `draft_info.json.PRE_CC_BAK` ในโฟลเดอร์โปรเจกต์
ถ้าผลออกมาไม่ถูกใจ เอาไฟล์นั้นเขียนทับ `draft_info.json` กลับได้

**ทาง A ลบซับเดิมของ CapCut ให้เอง** — เพราะเราอ่านซับนั้นมาทำใหม่ ถ้าไม่ลบจะซ้อนกัน 2 ชั้นบนจอ
ของเดิมยังอยู่ในไฟล์สำรองครบ · อยากเก็บไว้เทียบใส่ `--keep-source`

**ทาง B/C "เพิ่ม" ซับ ไม่ได้ "แทนที่"** — ถ้าเคยมีซับอยู่แล้วจะได้ซับซ้อนกัน 2 ชั้น ลบของเก่าใน CapCut ก่อน

**🚨 ปิด CapCut ให้สนิทก่อนรันทุกครั้ง (Cmd+Q ไม่ใช่แค่ปิดหน้าต่าง)** — ถ้า CapCut เปิดค้างอยู่
ตอนมันถูกปิด **มันจะเขียนสถานะในหน่วยความจำทับไฟล์** งานที่เราเพิ่งเขียนหายหรือซ้อนกันได้
(เจอจริงตอนทดสอบ 1 ก.ย. 69 — ซับกลับมาซ้อนกันเพราะ CapCut เปิดค้างไว้ดูผล)

## 🪟 ใช้ Windows อยู่?

**ตอนนี้ยังไม่รองรับครับ ขอโทษด้วย** — เพราะโค้ดผูกกับ 2 อย่างที่เป็นของ Mac:

1. ที่อยู่โปรเจกต์ CapCut → `~/Movies/CapCut/User Data/Projects/com.lveditor.draft`
   บน Windows อยู่ที่ `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft`
2. วิธีเช็คว่า CapCut เปิดอยู่ไหม → ใช้ `pgrep` / `ps` ซึ่ง Windows ใช้ `tasklist` แทน

**แต่ถ้าคุณใช้ Claude อยู่แล้ว แก้เองได้ไม่ยาก** — โยนไฟล์ `cc.ts` กับ `capcut_cc.py` ให้ Claude แล้วบอกว่า
*"ช่วยแก้ให้รองรับ Windows ด้วย: path โปรเจกต์เปลี่ยนเป็น %LOCALAPPDATA% และเปลี่ยนวิธีเช็คโปรเซสจาก pgrep เป็น tasklist"*

ถ้าใครแก้แล้วใช้ได้ **ส่งกลับมาให้ผมได้เลย จะได้แจกต่อให้คนอื่น**

## ของที่ยังไม่สมบูรณ์ (บอกไว้ก่อน)

- **แบ่งบรรทัดยังไม่เข้าใจความหมาย** — มันทำตามกฎการตัดคำ ไม่ได้เข้าใจว่าประโยคจบตรงไหน
  บางบรรทัดยังหั่นกลางความหมายอยู่ เช่น `หลายคนน่ะไม่ได้` / `วางแผนเลย...`
  **ถ้าอยากได้แบบเข้าใจความหมายจริง ต้องให้ AI ช่วยแบ่ง แล้วส่งเข้า `--phrases`**
- **ตัวนี้พึ่งโครงไฟล์ของ CapCut ที่ทางนั้นไม่ได้ประกาศ** — CapCut อัปเดตใหญ่เมื่อไหร่อาจพังได้ ผมรับประกันความต่อเนื่องให้ไม่ได้
- ยังไม่รองรับการแก้ซับที่ใส่ไปแล้ว (ต้องลบแล้วใส่ใหม่)

```
    └── stt_local.py   ← ถอดเสียงด้วย whisper ในเครื่อง (ฟรี)
```

**อยากแก้คำที่ถอดเสียงผิดบ่อยของคุณเอง** (เช่นชื่อร้าน ชื่อแบรนด์) → แก้ตาราง `FIX` ใน `make_subs.py`
